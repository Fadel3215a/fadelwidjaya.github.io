Project case studies use folder-based URLs (e.g. `/projects/opspilot/`) — the standard GitHub Pages pattern for clean paths without build tools.

## Run locally

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.

## GitHub Pages

1. Push to GitHub.
2. **Settings → Pages** → Deploy from branch **main**, folder **/ (root)**.
3. Site available at `https://fadelwidjaya.github.io`.

- Case study expansion content (implementation details, reflections, playbook publication)
