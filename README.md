# fadelwidjaya.github.io

Personal professional portfolio for Muhhammad Fadel Widjaya Baslin. The site is built with semantic HTML, custom CSS, and vanilla JavaScript for GitHub Pages.

Project case studies use folder-based URLs, such as `/projects/opspilot/`, which work well with GitHub Pages and provide clean paths without a build system.

## Technology

- HTML5 for page structure and content
- CSS3 for responsive layout, visual design, and animations
- Vanilla JavaScript for navigation, active-section highlighting, dynamic year text, and scroll reveals
- GitHub Pages for hosting

There are currently no package dependencies, frameworks, or build steps.

## Run locally

From the repository root, start a local static server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select deployment from the `main` branch and the `/ (root)` folder.
4. Visit the published GitHub Pages URL.
