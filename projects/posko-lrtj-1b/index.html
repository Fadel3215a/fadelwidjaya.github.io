Executive Summary

Built an automated end-to-end operational pipeline to ingest, parse, and structure unstructured daily monitoring reports from the POSKO LRT Jakarta Phase 1B WhatsApp coordination group into a centralized Google Sheets database. Replaced manual log transcription across multiple operational sub-systems (TPSS, Platform Screen Doors, OCC Signaling, and LRV) with real-time AI field extraction, automated schema routing, and dual-channel notification loops.

Key Technical Highlights & Engineering Decisions

Event-Driven Real-Time Ingestion (Node.js + Baileys)

  • Engineered a lightweight Node.js daemon using Baileys to hook into WhatsApp Web sockets.
  • Implemented targeted JID filtering (120363429448950939@g.us) and regex-based header identification (LAPORAN HARIAN, MONITORING, LOG OCC) to eliminate noise and casual messages.
  • Built session auto-reconnection with Exponential Backoff and a local HTTP management API for backfilling missed messages.

Fault-Tolerant AI Extraction Cascade (FastAPI + Google Gemini API)

  • Designed a multi-tier fallback architecture (gemini-3.8-flash → gemini-3-flash-preview → gemini-3.1-flash-lite) to guarantee structured JSON output during 429 Rate Limits or 503 API spikes.
  • Handled Indonesian railway terminology and varied shift formatting deterministically, extracting over 20+ operational parameters per report type without hardcoded regex rules.

Schema-Aware Tab Routing & State Persistence (Google Sheets API)

  • Automated header matching and dynamic row insertion across distinct sheet tabs (TPSS, PSD_PLATFORM, OCC_SIGNALING, Log_LRV).
  • Implemented custom SSL socket pool refreshing (cache_discovery=False) and retry loops to prevent transport drops during long AI fallback delays.
  • Integrated an in-memory deduplication layer to skip redundant posts during bulk imports and live socket retries.

Dual-Mode Operation (Live Sync & Historical Bulk Import)

  • Developed a companion bulk import CLI tool (bulk_upload.py) to process multi-month historical .txt chat exports, normalizing legacy data backlogs into the active operational sheet.
